# Salute a Te · Proposta de tour 360°

[Abrir prévia navegável](https://mgtour360graus.github.io/salute-a-te-preview/)

Proposta visual para aprovação do cliente, criada pela MG Tour em 19/11/2026. Versão 0.1.1.

Recepção, sala de espera e consultório em uma composição clássica, com marfim, preto, dourado, vidro translúcido, profundidade e transições suaves.

As imagens são ilustrativas e foram criadas por IA. Não são fotografias da clínica nem panoramas esféricos. A integração com o tour real 3DVista é posterior à aprovação visual.

## Compatibilidade

Alvo: iOS/Safari 14, 15, 16, 17 e 18. A interface inclui alternativas para diálogos, espaçamento flex, altura dinâmica e áreas seguras. Testes de navegador e emulação não equivalem a testes físicos. [Registro e roteiro](COMPATIBILIDADE-IOS.md).

## Arquivos

- `index.html`: prévia modular publicada.
- `mg-tour-skin/`: composição, configuração e imagens otimizadas.
- `capa/thumbnail-1920x1080.jpg`: capa em JPG.
- `MAIN-VIEWER-INICIAR.js`: ponte preparada; mapeamento nativo e integração real pendentes.

Marca preservada a partir do [Instagram informado](https://www.instagram.com/saluteate.clinic/). Referência de experiência: [Flosser / Mozak](https://mozak360.com/tour/flosser/). Interface própria para Salute a Te. Sem rastreamento ou formulário que colete dados.
